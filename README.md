# Python-Fundamentals-Assessment
Python fundamentals assessment: Beginner programs covering conditionals, loops, strings, and functions.

# Python Fundamentals

Here are the six beginner-level Python programs that demonstrate core programming concepts, including conditional statements, loops, string handling, and functions.

## Programs

| # | File | Description |
|---|------|-------------|
| 1 | `question1_even_odd.py` | Checks whether a given integer is even or odd |
| 2 | `question2_largest.py` | Finds the largest of three numbers |
| 3 | `question3_sum.py` | Calculates the sum of numbers from 1 to N |
| 4 | `question4_vowels.py` | Counts the vowels in a string |
| 5 | `question5_reverse.py` | Reverses a string |
| 6 | `question6_calculator.py` | Performs basic arithmetic using separate functions |

## Concepts Covered

- Variables and data types
- Input and output
- Operators
- Conditional statements (`if`, `elif`, `else`)
- Loops (`for`)
- String manipulation
- Functions

## Requirements

- Python 3.x

## Usage

1. Clone the repository:
   ```bash
   git clone https://github.com/Harischandra-Prasad-Vissamsetti/python-fundamentals-assessment.git
   cd python-fundamentals-assessment
   ```

2. Run any program:
   ```bash
   python question1_even_odd.py
   ```
